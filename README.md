# Crop_Disease

DATASET :- https://www.kaggle.com/datasets/emmarex/plantdisease/data    (go to this link for the dataset)

🚀 Excited to share my latest project – **Crop Disease Detection using Machine Learning & Computer Vision**! 🌱📸

With the agricultural sector facing massive challenges due to plant diseases, timely diagnosis can make a huge difference in crop yield and farmer income.
So, I built a web-based system that:

🔹 Allows users to upload a leaf image or capture one using the webcam
🔹 Uses ML image classification to detect disease
🔹 Shows prediction results with confidence scores
🔹 Provides a clean and responsive UI built with HTML, CSS, JS & Tailwind
🔹 Backend powered by Python & Flask

💡 Key Technologies Used:

* Python
* TensorFlow / CNN
* Flask
* HTML, CSS, JavaScript
* Webcam & Image Processing

🌾 Why this project?
To help farmers and agricultural systems adopt proactive disease management using AI-driven solutions.

Would love to connect with others working in **AI for agriculture**, **computer vision**, and **applied ML**! 🤝
